# Kakwa Dispatch

Phase 0 winter demo. One Alpine.js page shares a sample storm between the office board and a driver phone.

```sh
npm install
npm run dev
```

Open the local URL Vite prints. Desktop shows dispatch and the phone together. A narrow window has an Office / Driver switch. Refreshing clears the sample logs.

GitHub Pages serves the built `docs` folder, not the source. After a UI change, run `npm run build` and commit `docs` before pushing. The published site is [https://tokr-coder.github.io/Kakwa-dispatch/](https://tokr-coder.github.io/Kakwa-dispatch/).
