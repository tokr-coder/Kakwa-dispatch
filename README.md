# Kakwa Dispatch

Phase 0 winter demo. One Alpine.js page shares the dispatch board and the driver phone.

```sh
npm install
npm run dev
```

Open the local URL Vite prints. Desktop shows dispatch and the phone together. A narrow window has an Office / Driver switch. Refreshing clears the sample logs.

The published site is [https://tokr-coder.github.io/Kakwa-dispatch/](https://tokr-coder.github.io/Kakwa-dispatch/). A push to this branch runs the Deploy GitHub Pages workflow. The editable app is in `site/`.
