# Kakwa Dispatch

Phase 0 winter demo. Quinn plans a snow shift on a phone: pick a site, tap the machines it needs, confirm the drivers, then order the night as a sequence.

```sh
npm install
npm run dev
```

Open the local URL Vite prints. The page is a single column. Refreshing clears the plan.

The published site is [https://tokr-coder.github.io/Kakwa-dispatch/](https://tokr-coder.github.io/Kakwa-dispatch/). A push to this branch runs the Deploy GitHub Pages workflow. The editable app is in `site/`.
